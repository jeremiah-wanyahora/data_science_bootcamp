# 30-Day Python for Data Science Bootcamp

This is my personal 30-day journey to transition from a Google-certified Data Analyst to a Data Scientist. I'm focusing on Python, data analysis libraries, and practical projects — all documented in this repository.

## Week 1: Python Fundamentals

| Day | Topic                          | Focus                                                   |
|-----|--------------------------------|----------------------------------------------------------|
| 1   | Python Setup & Syntax          | VS Code, Git, print, variables, data types               |
| 2   | Control Flow & Functions       | if/else, loops, defining and calling functions           |
| 3   | Lists, Tuples & Dictionaries   | Data structures and how to iterate over them             |
| 4   | String Manipulation            | String methods, slicing, f-strings                       |
| 5   | Input/Output & Practice        | User input, simple calculator, file basics               |
| 6   | Review + Mini Project          | Build a budget tracker or name analyzer                  |
| 7   | Rest + Git Practice            | Git commits, branches, and .gitignore setup              |

## Week 2: NumPy & Pandas Essentials

| Day | Topic                          | Focus                                                   |
|-----|--------------------------------|----------------------------------------------------------|
| 8   | NumPy Arrays                   | Array creation, slicing, indexing                        |
| 9   | NumPy Operations               | Math functions, stats, broadcasting                      |
| 10  | Pandas Series                  | Creating and manipulating Series                         |
| 11  | Pandas DataFrames              | Reading CSV files, exploring structure                   |
| 12  | DataFrame Indexing             | loc, iloc, filtering rows and columns                    |
| 13  | Cleaning Data                  | dropna, fillna, type conversions                         |
| 14  | Review + File Handling         | Reading/writing CSV, Excel, JSON                         |

## Week 3: Data Visualization & EDA

| Day | Topic                          | Focus                                                   |
|-----|--------------------------------|----------------------------------------------------------|
| 15  | Matplotlib Basics              | Line, bar, scatter plots, titles                         |
| 16  | Customizing Visuals            | Legends, colors, figure size, axes                       |
| 17  | Seaborn Basics                 | countplot, histplot, barplot                            |
| 18  | Pairplots & Heatmaps           | pairplot, heatmap, correlation matrix                    |
| 19  | EDA on Real Dataset            | Analyze Titanic or Iris dataset                          |
| 20  | Mini EDA Project               | Your own dataset + charts and insights                   |
| 21  | Rest + Insight Summary         | Practice sharing insights from data                      |

## Week 4: Real Projects & Capstone

| Day | Topic                          | Focus                                                   |
|-----|--------------------------------|----------------------------------------------------------|
| 22  | Real-World Dataset Setup       | Import, inspect, explore data                            |
| 23  | Feature Engineering            | Rename, encode, scale features                           |
| 24  | GroupBy & Aggregation          | groupby, agg, descriptive stats                          |
| 25  | Pivot Tables & Time Series     | pivot_table, datetime parsing, resampling                |
| 26  | Merging & Joining              | merge, concat, relational data                           |
| 27  | Capstone Project - Part 1      | Problem setup, data loading and cleaning                 |
| 28  | Capstone Project - Part 2      | Exploratory analysis, charts, summary                    |
| 29  | Capstone Project - Finalize    | Write report, clean code, create visuals                 |
| 30  | Portfolio & Sharing            | Publish on GitHub, update README, reflect                |
